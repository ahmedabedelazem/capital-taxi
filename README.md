# تاكسي العاصمة | CAPITAL TAXI

منصة نقل ذكية مخصصة للعريش وشمال سيناء، بثلاث بوابات: العميل والسائق والإدارة.

## الحالة الحالية
هذه مرحلة تأسيس الواجهة والبنية الأمامية. لا يوجد حالياً ربط تشغيلي بقاعدة Firebase أو نظام توزيع رحلات حي؛ ولا تُعتبر أي ميزة تشغيلية مكتملة قبل تنفيذها واختبارها.

## التقنية
- Next.js App Router + TypeScript
- Tailwind CSS
- واجهة عربية RTL ومتجاوبة
- هوية Premium Dark Luxury

## التشغيل المحلي
```bash
npm install
cp .env.example .env.local
npm run dev
```
ثم افتح http://localhost:3000

## المسارات
- `/` الصفحة الرئيسية
- `/customer` بوابة العميل
- `/driver` بوابة السائق
- `/admin` بوابة الإدارة

## الأمان
- التحقق من الصلاحيات يجب أن يتم على الخادم.
- لا تعدّل المحافظ أو العمولات من العميل مباشرة.
- قبول الرحلة يجب أن يكون ذرياً عبر Backend موثوق.
- لا تُعرض بيانات التواصل قبل الإسناد وفق سياسة واضحة.
- قواعد Firebase والبيانات الحقيقية خارج نطاق هذه المرحلة.
